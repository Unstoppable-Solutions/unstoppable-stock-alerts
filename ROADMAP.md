# Roadmap

This document outlines planned features and improvements for Unstoppable Inventory Alerts for WooCommerce.

## Current Version: 1.1.7

## Short Term (Next Release)

### v1.2.0 - WordPress Compatibility Update

- [ ] Update "Tested up to" to WordPress 7.1.3
- [ ] Verify compatibility with latest WooCommerce version
- [ ] Performance testing and optimization
- [ ] Additional unit tests

## Medium Term (Next Quarter)

### Enhanced Analytics Dashboard

- [ ] Advanced reporting with date range filtering
- [ ] Conversion tracking (subscriptions → purchases)
- [ ] Product performance insights
- [ ] Email delivery success rates
- [ ] Export reports as PDF

### Email Enhancements

- [ ] Customizable email templates in admin
- [ ] Multiple notification templates per product category
- [ ] Email preview functionality
- [ ] A/B testing for email subject lines
- [ ] Scheduled email sending (don't send at 3 AM)

### Subscriber Management

- [ ] Bulk import subscribers from CSV
- [ ] Subscriber segmentation by purchase history
- [ ] Automatic cleanup of bounced/invalid emails
- [ ] Subscriber preferences (frequency, categories)
- [ ] GDPR-compliant data export

## Long Term (Next 6 Months)

### Integration Expansion

- [ ] Mailchimp integration
- [ ] Klaviyo integration
- [ ] Zapier integration
- [ ] Webhook support for custom integrations
- [ ] REST API for third-party applications

### Advanced Features

- [ ] SMS notifications (via Twilio)
- [ ] Push notifications (via OneSignal)
- [ ] Price drop alerts (companion feature)
- [ ] Back-in-stock predictions using historical data
- [ ] Multi-site network support

### Performance & Scale

- [ ] Background processing for large catalogs
- [ ] Database table optimization for high-traffic stores
- [ ] Caching improvements
- [ ] API rate limiting

## Completed

### v1.1.x Series
- [x] Plugin renamed to "Unstoppable Inventory Alerts"
- [x] Security hardening (nonce verification, CSV injection protection)
- [x] Chart.js updates
- [x] WordPress.org compliance fixes
- [x] PHPCS compliance

### v1.0.x Series
- [x] Initial release with core functionality
- [x] AJAX subscription forms
- [x] Admin dashboard with charts
- [x] Email queue with cron processing
- [x] Variable product support
- [x] WooCommerce HPOS compatibility
- [x] Cart & Checkout Blocks compatibility
